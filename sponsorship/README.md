# Partenariats fondateurs PrivAI

## Proposition

PrivAI recherche des **Founding Evidence Partners** pour financer une preuve
ouverte : le premier test public de migration d’un agent mandaté entre deux
environnements, avec conservation vérifiable du principal, du mandat, de la
mémoire source et du journal d’actes.

Le livrable initial est [Migration-Tested v0.1](../conformance/migration_tested_v0.1.md),
un profil ouvert accompagné d’une démonstration, de tests automatisés et d’un
rapport transparent sur les réussites comme sur les pertes.

> L’interopérabilité ne promet pas l’absence de pouvoir ; elle empêche qu’un
> pouvoir technique devienne irrévocable par défaut.

## Contributions recherchées

- crédits d’usage ou accès borné à des modèles et API ;
- contribution à un adaptateur public ;
- temps d’un interlocuteur technique ;
- financement borné de spécification, de tests et de démonstration.

## Garanties d’indépendance

| Acceptable | Exclu |
|---|---|
| crédits d’usage bornés | exclusivité de fournisseur |
| financement d’un adaptateur public | propriété du noyau ou du référentiel |
| relecture des éléments techniques concernant le partenaire | droit de réécrire les conclusions |
| étude de cas factuelle | approbation préalable générale des publications |
| accès temporaire à une API | dépendance à un format sans export documenté |

Un partenaire finance la preuve que son offre demeure choisissable lorsque
l’utilisateur garde le contrôle de son identité, de sa mémoire, de ses mandats
et de sa faculté de partir. Le soutien ne vaut ni endorsement général ni
préférence commerciale.

## Positionnement

PrivAI distingue le référentiel de ses implémentations. Cogentia peut en être
la première démonstration de référence. Tout autre logiciel, opérateur ou
fournisseur peut publier une épreuve dans les mêmes conditions.

La liste de contacts ou de prospects n’est pas publiée ici : elle relève d’une
préparation relationnelle révisable. Les soutiens effectivement acquis et les
conditions publiques correspondantes pourront être inscrits dans un registre.
